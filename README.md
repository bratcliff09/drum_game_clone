# Drum Game Clone

### Purpose of this project

Creating a clone of the rhythm game Taiko using PyGame

### Dependencies:

PyGame-CE

### Instructions

Install PyGame-CE - pip install pygame-ce

Make the project folder your current working directory

Run the main python file - py main.py

### Controls

Esc - Exits some screens or options

Enter - Select a menu option

D K - Input for blue notes

F J - Input for red notes
